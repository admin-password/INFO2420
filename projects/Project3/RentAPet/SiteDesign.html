Rent A Pet – Site Color Scheme

Color scheme designed for Rent A Pet using a warm, earthy base (fitting for a pet-related business) paired with a cooler complementary blue accent for links, chosen for strong contrast against the light background.

SwatchUseHex Value
 Page background#FAF3E8
 Body text#3E2F25
 H1 heading#B5541F
 H2 heading#8C5A2B
 H3 heading#70451F
 Link (a:link)#2C6E8E
 Visited link (a:visited)#6B4C3A
 Hover/focus link (a:hover, a:focus)#A14A1A
 Active link (a:active)#5C2D0C
 Blockquote background#F0E4D3

Contrast checked against the background color (#FAF3E8) using a WCAG contrast ratio calculator:

  • Body text: 11.6:1 (passes AA and AAA)
  • Links (a:link): 5.1:1 (passes AA)
  • Visited links: 7.0:1 (passes AA and AAA)
  • Hover/focus links: 5.4:1 (passes AA)
  • H2/H3 headings: 5.2:1+ (passes AA)
  • H1 heading: 4.5:1 (passes AA for large text)
